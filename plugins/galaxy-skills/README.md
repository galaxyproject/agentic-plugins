# galaxy-skills (mirror)

Everything under `skills/` is a verbatim copy of upstream; **do not edit it
here**. Upstream: https://github.com/galaxyproject/galaxy-skills. The pinned commit is recorded in `UPSTREAM.json`.

Refresh with `scripts/sync-skills.sh` from the repository root (a scheduled
GitHub Action does this weekly and opens a pull request). The manifests in
this directory are regenerated by `scripts/gen-manifests.py`.
